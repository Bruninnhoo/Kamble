# Web

Next.js 16, React 19 e Tailwind CSS 4. Instalação e variáveis de ambiente estão no [README principal](../../README.md#rodar-localmente).

| Comando, em `apps/web` | Efeito                        |
| ---------------------- | ----------------------------- |
| `pnpm dev`             | Inicia com recarga automática |
| `pnpm build`           | Build de produção             |
| `pnpm start`           | Serve o build                 |

Organização do código: [arquitetura](../../docs/ARQUITETURA.md#web).
